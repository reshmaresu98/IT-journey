# IT-journey

Start with HTML

Heading
Heading tag = <h1>...</h1> to <h6>...</h6>
heading tag has opening and closing tag.
<h1> provide largest font size, big heading.</h1>
<h6> provide small heading.</h6>
We use <h1></h1> tag to write big heading like news paper and <h2></h2>, <h3></h3> to write second important heading.

Paragraph

Paragraph also has starting and ending tag.
Paragraph tag= <p>...</p>
Normally we use <p> tag to write body paragraph.
